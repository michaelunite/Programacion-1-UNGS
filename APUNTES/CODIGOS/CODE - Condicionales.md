# Código: Condicionales

```java
public class Condicionales {
    public static void main(String[] args){

        // Estructura básica de un if
        int numero = 4;
        
        if (5 > numero) {
            System.out.println("5 es mayor a: " + numero);
        }

        /* 
           COSAS A TENER EN CUENTA:
           
           1. Expresiones booleanas:
              Se usan operadores relacionales (==, !=, >, <, >=, <=) 
              y lógicos (&&, ||, !) para crear la condición.
           
           2. Ámbito (Scope):
              Las variables creadas dentro de un if { ... } mueren al salir de las llaves.
        */
    }
}
```
